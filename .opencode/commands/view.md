# /view

1. `./pq build`.
2. Ouvre `site/index.html` (ou `site/$ARGUMENTS.html` si un id est donné) : `./pq view` ouvre le tableau de
   bord dans le navigateur par défaut ; si ton outil a un navigateur intégré, tu peux l'y ouvrir.
