Arrière-petit-fils de [[pierre-espinas]] par la lignée cadette : son grand-père est
[[francois-espinas-fils-de-pierre]], « François 1er du nom », dont le testament de 1599 mentionne le fils François,
second du nom [[bnf-fr-32552.a6]] ; ce second François est le père de Jean-Auguste [[aubais-pieces-fugitives.a6]].
Jean-Auguste passe un accord le 22 juillet 1646 [[aubais-pieces-fugitives.a6]]. Le 2 août 1669, il est maintenu noble
avec [[gabriel-espinas]] ([[maintenue-des-espinas-de-cardonne-1669]]) ; le jugement le dit « aussi Sr de Cardonne,
demeurant au diocèze de Rieux », alors que Gabriel demeure au diocèse de Mirepoix [[bnf-fr-32552.a1]]
[[catalogue-de-caux-1676.a1]] [[bremond-1863.a1]] [[aubais-pieces-fugitives.a7]]. Les deux branches issues de Pierre
portaient donc toutes deux le titre de Cardonne, dans deux diocèses.
